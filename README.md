# OTA-Unity: 输电线路走廊三维激光点云数字孪生平台

**OTA-Unity** 是一款面向电力行业（国家电网 / 南方电网）、无人机激光雷达巡检以及 GIS 三维数字孪生的高性能桌面端平台。基于 Unity 引擎深度研发，专为海量激光点云（LAS / LAZ）高帧率渲染、输电通道四级拓扑资产管理、杆塔与导线交互式空间标定、DL/T 5582 导线悬链线力学分析与净空安全核验打造。

---

## 核心功能特性

### 1. ⚡ 海量激光点云高性能渲染 (GPU Compute Shader)
* **百万/千万级点云实时 60FPS 渲染**：基于 DX11 Compute Shader 与 Structured Buffer 硬件管线优化。
* **双模式色彩渲染平滑互切**：支持点云真实 RGB 色彩与高程渐变伪彩色一键切换。
* **ASPRS 类别图例与过滤系统**：支持地面、低/中/高植被、导线、杆塔等分类的单项/批量显示与显隐过滤。

### 2. 🌐 输电走廊四级拓扑资产管理 (Corridor Hierarchy)
* **规范化四级资产树**：按照【省份 ➔ 地市 ➔ 线路 ➔ 档距区段】分层组织走廊资产。
* **元数据自动探测**：本地载入 LAS/LAZ 点云时自动解析空间参考系（CRS）、高斯投影带、中央子午线及包围盒边界。
* **视口资产精准联动**：双击资产节点自动平滑聚焦相机到对应杆塔或导线跨段。

### 3. 🗼 空间交互标定与特征提取 (Annotation & Extraction)
* **杆塔空间标定**：`Shift + 点击`放置杆塔中轴底部靶点，采用塔头/塔身双包围盒，支持 `Shift + 滚轮` 微调朝向偏角（Yaw）及 `Shift + 右键拖拽` 交互拉伸呼高和横担宽度。
* **导线标定与悬链线拟合**：交互拾取空间悬链特征点，系统自动基于悬链线物理方程拟合三维导线，实时计算跨中实测弧垂，并反演导线外径与规程型号。
* **选区修点与语义重分类**：视口内矩形拉框快速选区，一键批量重置 ASPRS 类别编号，并支持直接写回持久化到 LAS 文件。

### 4. 📏 全三维真空间原位测量 (In-World 3D Measurement)
* **无遮挡真三维原位呈现**：彻底摒弃传统屏幕顶部 2D 文本遮挡卡片。
* **测点原位三维锚定**：`Shift + 点击` 依次标记空间起点 A 与终点 B。
* **空间看板动态指示**：在三维连线中点原位悬浮展示【空间直线距】、【水平投影距】与【垂直净空高差】，看板面向摄像机并自带一键清空重测交互。

### 5. 📐 DL/T 5582 导线力学与工况仿真引擎 (Power Mechanics Engine)
* **电力行业标准严谨建模**：严格遵循国家电力行业标准《DL/T 5582 输电线路导线力学计算导则》。
* **气象工况状态方程仿真**：支持最高气温、大风、覆冰、年均气温、外过电压等不同典型气象工况下的应力、张力与弧垂仿真计算。
* **绝缘子风偏与施工放样**：内置绝缘子串风偏摇摆角核验，以及架线施工放样张力表实时生成。

### 6. 🗺️ GIS 与数据预处理辅助 (GIS & Stream Cutter)
* **天地图底图瓦片集成**：支持天地图高精度卫星正射影像底图服务接入。
* **坐标投影转换引擎**：实现 WGS84 经纬度、UTM 与高斯-克吕格投影平面坐标系的双向高精度转换。
* **走廊流式切片工具**：支持 2D 地图交互划线并流式切割大体量 LAS 点云导出子切片。

### 7. 🎨 国家电网 (SGCC) 科技工业风交互界面 (Industrial UI/UX)
* **调度中心工业质感**：采用高对比度石油深黑控制台底板（`#071311`），搭配国家电网绿（`#008470`）、高压金（`#F5A623`）与导线霓虹青（`#00D2B4`）。
* **漫游预设视角浮层**：在顶部【漫游 ▾】菜单内集成正视、俯视、侧视、轴测等标准工程观察视角。
* **实时操作引导跑马灯**：TopBar 正下方 24px 动态悬浮栏，根据当前操作模式自适应滚动快捷键操作指南。

## 运行环境与配置需求

| 项目 | 要求规范 |
|---|---|
| **Unity 引擎版本** | 2019.4.19f1 LTS（兼容 2019.4.x） |
| **脚本后端与运行时** | .NET 4.x / NetStandard 2.0，C# 7.3 |
| **图形渲染接口** | DirectX 11（必须支持 Compute Shader 5.0） |
| **操作系统** | Windows 10 / 11 64-bit |
| **推荐硬件配置** | CPU Intel i7/AMD R7 以上，内存 16GB+，显卡 NVIDIA GTX 1060 / RTX 2060 以上 |

## 快速上手与操作指南

### 1. 工程克隆与打开
1. 使用 Git 克隆本仓库到本地环境；
2. 使用 **Unity Hub** 添加并使用 **Unity 2019.4.19f1** 打开工程；
3. 打开工程主场景：`Assets/Scenes/P0-LasView.unity`；
4. 点击 Unity 编辑器顶部 **Play (运行)** 按钮进入数字孪生交互系统。

### 2. 常用操作快捷键

| 快捷操作 | 交互行为 |
|---|---|
| **鼠标右键拖拽** | 旋转观察场景视口角度 |
| **鼠标中键 / 滚轮按住拖拽** | 平移场景视口 |
| **鼠标滚轮滑动** | 推进 / 拉远缩放视角 |
| **F 键** | 镜头快速居中聚焦当前选中的杆塔或导线资产 |
| **Shift + 鼠标左键点击** | 标定杆塔中轴 / 标定导线挂点 / 3D空间测距选点 |
| **Shift + 鼠标滚轮滑动** | 旋转当前选中杆塔朝向偏角（Yaw） |
| **Shift + 鼠标右键拖拽** | 调整当前杆塔呼称高（上下拖）与横担宽度（左右拖） |
| **鼠标左键拉框拖拽** | 【选区修点】模式下矩形框选点云簇 |

## 核心代码目录架构

```text
Assets/
├── Editor/                         # 编辑器扩展与编译脚本工具
├── LitJson/                        # 高性能轻量级 JSON 序列化库
├── PointCloudTools/                # DX11 Compute Shader 点云底层驱动引擎
│   └── PointCloudViewerDX11/       # 实时千万级点云着色与结构化缓冲区调度
├── Resources/                      # 运行时材质、着色器与系统动态资产
├── Scenes/                         # 核心运行场景 (P0-LasView.unity)
└── Scripts/                        # 核心业务源码
    ├── Compat/                     # 跨版本与点云兼容适配层
    ├── Corridor/                   # 输电走廊主业务层
    │   ├── Annotation/             # 杆塔/导线三维空间标定、包围盒与3D测量
    │   ├── Hierarchy/              # 走廊四级拓扑树与 LAS 元数据嗅探
    │   ├── Mechanics/              # DL/T 5582 力学计算、状态方程与风偏核验
    │   ├── Overlays/               # 塔线三维覆盖层渲染与特征提取
    │   ├── Preprocess/             # GIS 坐标转换、天地图底图与点云流式切片
    │   └── UI/                     # 国家电网科技工业风 HUD、主题系统与模态窗
    └── P0OrbitCamera.cs            # 空间轨道漫游与轴测视口控制摄像机
```
